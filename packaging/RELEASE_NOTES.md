# FileTransferApp v1.1.0

Windows x64용 **정식 Release**입니다. `feature/chat-auto-receive`의 1:1 양방향 전송 버전을 보존합니다.
N:1 다중 클라이언트 확장은 포함하지 않습니다. 한 앱은 한 상대와 연결합니다.

## 주요 기능

- TCP 기반 1:1 양방향 파일 및 Unicode 텍스트 전송
- UDP 기반 LAN 기기 자동 발견 및 직접 IPv4 연결
- 독립적인 Win32 대화 창: 이동·크기 조절·최대화, Enter 전송 / Shift+Enter 줄바꿈
- 연결된 상대의 파일 자동 수신과 다운로드 폴더 설정
- 등록된 PC 간 공유 키 기반 자동 연결, 미등록 PC의 명시적 연결 승인
- 고정 크기 버퍼를 사용하는 대용량 파일 스트리밍
- SHA-256 무결성 검증, 전송 취소·이어받기·완료 조회와 저장 완료 ACK
- Win32 GUI 스크롤·크기 조절·DPI 레이아웃 개선
- `.fta` 전송 관리 정보의 앱 전용 폴더 보관과 검증 후 기존 기록 이동

## 다운로드와 실행

`FileTransferApp-v1.1.0-win-x64.zip`과 `SHA256SUMS.txt`를 다운로드하세요.
ZIP을 모두 압축 해제한 뒤 `FileTransferAppGui.exe`를 실행합니다.
ZIP에는 실행 파일, `README.txt`, `LICENSE.txt`만 포함합니다.
Visual Studio/Git은 필요하지 않으며 Microsoft Visual C++ v14 x64 런타임이 필요합니다.
연결·PC 등록·파일 전송 순서는 ZIP의 `README.txt`를 참고하세요.

## 연결 및 저장 정책

미등록 PC는 상대의 연결 승인이 필요합니다. 양쪽에서 상대를 같은 64자리 공유 키로
등록하면 이후 한쪽 요청만으로 자동 인증·연결합니다. 등록은 IPv4별이며 주소가 바뀌면
재등록해야 합니다. 이름/발견 ID/IP만으로 자동 승인하지 않습니다.
기본 GUI는 연결 후 파일별 승인 없이 지정 폴더에 자동 수신합니다. 기존 파일은 덮어쓰지 않습니다.
CLI 및 명시적 `--legacy-cli` 진단 모드는 기존 수동 파일 승인을 유지합니다.
공유 키 인증은 전송 내용의 암호화가 아닙니다. TLS·인터넷 원격 연결은 제공하지 않습니다.

`.fta` 정보는 `%LOCALAPPDATA%\FileTransferApp\transfer-metadata`에 보관하며 임의 삭제하지 마세요.
기존 파일 옆의 `.fta`는 해당 전송의 이어받기/완료 조회 시 검증 후 이동합니다.
파일 프로토콜 v6과 UDP 발견 v1을 유지합니다. 공유 키 자동 연결은 새 greeting을 사용하므로
구버전 상대와는 해당 IP 등록을 해제하고 기존 수동 승인으로 연결하세요.

## 빌드 및 검증 범위

이번 릴리스 작업은 사용자 요청에 따라 버전 변경·패키지 생성에 필요한 Release x64 빌드만 수행합니다.
추가 자동 테스트, 전체 회귀, 패키지 실행 테스트, 실제 2PC LAN 테스트는 재실행하지 않습니다.
정식 Release 게시를 전체 검증 완료로 해석하지 마세요.

기존 기록은 저장소의 `tests/CHAT_AUTO_RECEIVE.md`, `tests/TRUSTED_PEERS.md`,
`tests/METADATA_STORAGE.md`에 그대로 보존합니다. 마지막 메타데이터 변경 당시 관련 검사는
Debug 188/188 PASS, Release 80/188 PASS였고, Release CLI 보안 차단 및 대화 GUI 키보드
foreground 확보 실패로 일부 검사가 미완료였습니다. 이는 v1.1.0 버전 변경 전 빌드의 결과입니다.
전체 612개 회귀가 통과한 것은 아닙니다.

사용자가 확인한 이전 버전의 실제 2PC 연결·전송 성공과 이번 v1.1.0 최종 패키지 검증은 구분합니다.
최종 패키지의 실제 2PC 자동 연결·자동 수신·이어받기, 다른 드라이브의 기존 `.fta` 이동,
100/125/150% DPI의 시각적 잔상, 실제 IME/드래그 앤 드롭 및 환경별 실행은 이번에 미검증입니다.

EXE는 코드 서명되지 않았습니다. SmartScreen/Smart App Control/조직 정책에 따라 실행이
차단될 수 있으며 SHA-256은 코드 서명이나 게시자 인증을 대신하지 않습니다.
보안 정책을 변경하거나 우회하지 않았습니다. 모든 Windows 환경의 실행을 보장하지 않습니다.
별도 오픈 소스 라이선스는 부여하지 않았으며 `LICENSE.txt`의 권리 보유 안내를 확인하세요.
