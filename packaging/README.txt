FileTransferApp v{{VERSION}} — N:1 다중 클라이언트 (Windows x64)

기존 v1.1.0은 1:1 버전이며 이 패키지는 N:1 버전입니다.
ZIP을 모두 압축 해제하고 FileTransferAppGui.exe를 실행하세요.
Microsoft Visual C++ v14 x64 런타임이 필요합니다.

사용 순서
1. 서버 PC에서 서버 모드와 이름을 선택하고 역할/이름 적용을 누릅니다.
2. 다른 PC에서 클라이언트 모드와 이름을 적용합니다.
3. 클라이언트의 LAN 목록에서 서버 선택 → 선택 기기 연결 요청.
   목록에 없으면 서버의 LAN IPv4와 화면의 실제 TCP 포트를 입력합니다.
   다른 PC에는 127.0.0.1로 연결하지 마세요.
4. 서버에서 미등록 상대의 연결 요청을 승인합니다.
5. 연결 목록에서 상대 선택 → 파일 선택 → 파일 보내기.
   연결된 상대의 파일은 자동 수신하며 양방향 전송이 가능합니다.
6. 대화 창 열기: Enter 전송, Shift+Enter 줄바꿈.
   대화 창만 닫아도 연결 및 파일 전송은 유지됩니다.

서버 최대 10개 클라이언트, 클라이언트는 서버 하나에 연결합니다.
서버 기본 수신 위치: <기본 다운로드 폴더>\peers\<영속 PeerId>
상대 선택 후 상대 폴더 변경 / 기본 경로 복원으로 설정합니다.
이미 수락한 전송의 경로는 변경되지 않습니다.
클라이언트 수신 파일은 클라이언트 자신의 다운로드 폴더에 저장됩니다.
동일 폴더의 같은 파일명은 안전하게 거부하며 기존 파일을 덮어쓰지 않습니다.

PC 등록
양쪽에서 상대를 선택하고 동일한 소문자 64자리 16진수 공유 키로 등록하면
이후 인증된 연결은 자동 승인됩니다. PC 쌍마다 다른 키를 사용하세요.
발견된 이름과 미등록 PeerId만으로 상대를 신뢰하지 마세요.

같은 Windows 사용자로 두 번 실행하면 PeerId와 설정을 공유합니다.
동일 PeerId는 자기 자신으로 처리하여 LAN 목록과 연결에서 제외됩니다.
서로 다른 PC에서 실행 파일만 옮겨 실행하고 PC 설정을 복사하지 마세요.
PeerId 파일을 삭제하면 등록 및 복구에 영향을 줄 수 있습니다.

복구 및 호환성
.part는 수신 폴더에, .fta는 다음 경로에 저장됩니다.
%LOCALAPPDATA%\FileTransferApp\transfer-metadata
복구 정보를 삭제하지 마세요. 이어받기는 원래 수신 폴더에서 수행합니다.
N:1 복구 정보는 PeerId에 귀속됩니다.
v1.1.0과 연결할 때 FileTransferAppGui.exe --compat-v1 을 사용하세요.
기본 N:1 모드는 구버전과 자동 호환되지 않습니다.

검증 범위
개발본 Debug/Release 자동 검사 760/760 PASS 기록을 유지합니다.
이번 버전 변경 후 전체 회귀 검사는 재실행하지 않았습니다.
실제 다중 PC LAN, 10대 처리량, 장시간 운용, DPI/잔상/IME는 추가 확인이 필요합니다.
실행 파일은 서명되지 않았습니다. 보안 정책을 우회하지 마세요.
