# FileTransferApp v1.2.0 — N:1 다중 클라이언트

기존 **v1.1.0은 1:1 버전**으로 보존합니다. 이 Release는 `feature/n-to-1-multiclient`의 N:1 버전이며 main과 기존 태그/배포 파일을 변경하지 않습니다.

## 다운로드 및 실행
`FileTransferApp-v1.2.0-win-x64.zip`을 받아 모두 압축 해제하고 `FileTransferAppGui.exe`를 실행하세요. Source code ZIP은 실행용 패키지가 아닙니다.
ZIP에는 GUI 실행 파일, 한국어 사용 안내, 권리 보유 안내만 포함됩니다. Microsoft Visual C++ v14 x64 런타임이 필요합니다.

## 주요 기능
- 서버 최대 10개 독립 세션, 클라이언트별 양방향 파일·텍스트 전송
- 서버/클라이언트 역할 및 이름 설정, UDP LAN 발견
- 영속 PeerId와 PC 쌍별 공유 키 인증, 미등록 상대 수동 승인
- 상대별 독립 대화 창, 자동 파일 수신
- 서버의 PeerId별 영속 다운로드 경로 및 안전한 기본 개별 하위 폴더
- 스트리밍, 취소·이어받기, SHA-256 검증, 완료 ACK 유지
- 전송 수락 시 수신 경로 고정 및 기존 파일 덮어쓰기 방지
- PeerId에 귀속된 중앙 .fta 복구 정보

## 사용 순서 및 호환성
서버 PC에서 서버 모드를 적용하고 다른 PC에서 클라이언트 모드를 적용합니다. 클라이언트에서 서버에 연결 요청을 보내고 서버에서 승인합니다. 연결 목록에서 상대를 선택해 파일을 보내거나 대화 창을 여세요.
양쪽에 동일한 공유 키를 등록하면 이후 인증된 연결은 자동 승인됩니다. PC 쌍마다 다른 키를 사용하세요.
같은 Windows 사용자로 두 번 실행하면 PeerId가 같아 서로 발견되지 않습니다. 다른 PC에서 실행하고 설정 파일을 복제하지 마세요.
기본 N:1 모드는 구버전으로 자동 fallback하지 않습니다. v1.1.0과 연결하려면 명시적 `--compat-v1` 모드를 사용하세요.
